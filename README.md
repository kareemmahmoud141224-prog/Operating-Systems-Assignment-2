# Operating Systems Assignment 2

## About

This assignment is about fork(), linker, loader and Makefile.

## Files

- process_creation.c : Create a new process
- file1.c : Print a message
- file2.c : Call hello()
- simple_program.c : Simple C program
- Makefile : Compile programs
- answers.txt : Code explanation

## Requirements

Linux, GCC and Make

## Installation

```
sudo apt install gcc
sudo apt install make
```

## Compile

```
make
```

## Run

```
./process_creation
./output_program
./simple_program
```

## Check Libraries

```
ldd simple_program
```
